# Проект сайта-визитки организации

## Структура проекта

- `index.html` — минимальная HTML5-страница с SEO-мета-тегами и подключением стилей и JavaScript.
- `css/styles.css` — файл стилей проекта.
- `js/main.js` — файл JavaScript-логики проекта.
- `favicon.svg` — иконка сайта.
- `assets/images/` — директория для изображений.
- `assets/icons/` — директория для иконок.
